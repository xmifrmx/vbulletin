# İkonlar
`assets/js/core/icons.js` Lucide (ISC) stilinde satır içi SVG kullanır; harici istek yoktur. Yollar Lucide geometrisine göre elle yerleştirilmiştir, birebir resmî dosyalar değildir.
Resmî sürüme geçmek için: `npm i lucide-static@<sabit sürüm>`, ilgili `.svg` dosyalarının iç öğelerini `icons.js` içindeki `P` nesnesine yapıştırın (anahtar adlarını koruyun).
